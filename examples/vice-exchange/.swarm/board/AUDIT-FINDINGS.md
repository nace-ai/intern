- **[medium] A single wallet can farm the house risk-free by trading against the expiry of its own sentiment entries (+263 per 80 s at a V$95 spot)** (`apps/server/src/economy/index.ts`): Make a wallet unable to benefit from its own entries still inside the window: store the wallet id on each demand entry (or derive the wallet's own net units from state.trades by actorId, ticker and atMs), then price the fill with effectiveNet = net - min(0, ownNet) for a BUY and net - max(0, ownNet) for a SELL. Simulating exactly that rule turns the same 4-cycle loop from +774 into -247 (.swarm/repro/economy/10-fix-c
- **[medium] Every tokenless join mints a permanent player, character and listing: one socket can grow the room without bound** (`apps/server/src/rooms/RoomManager.ts`): Retire a player that has been disconnected longer than a grace period (archive the character, halt or delist its listing when nobody else holds it, drop its per-character map entries). Cap total players per room and new-player joins per socket (for example 1 per 2 s). Skip survival repricing for listings whose owner is disconnected. Do not emit public events for role-forbidden or malformed-target rejections (ack only
- **[medium] Origin allow-list is not enforced: the Socket.IO WebSocket and /bridge accept connections from any web origin** (`apps/server/src/transport/app.ts`): Pass `allowRequest: (req, cb) => cb(null, originAllowed(req.headers.origin, o.webOrigin))` to the SocketIOServer, and in the bridge's onUpgrade destroy the socket when an Origin header is present and not allowed (the native Godot client sends none). Let WEB_ORIGIN be a comma-separated list so a tunnel origin can be allowed deliberately.
- **[medium] Anonymous room creators get director powers with server-wide effects: provider budgets multiply per room and one client can hold the global experiment runner** (`apps/server/src/engine/compose.ts`): Share one call budget and one in-flight limiter (and the provider clients) across all rooms: create them once in createRoomFactory or app.ts and hand them to every scheduler. Require the director secret for room.create, or start created rooms in scripted mode and require the secret for demo.setMode and demo.runExperiment there. Send experiment updates only to the room that started the run (io.to(room.code)).
- **[medium] Replay CLI resolves a room code to the newest boot only; recorded sessions from before a restart cannot be selected** (`apps/server/src/replay/cli.ts`): Print roomId in the listing and in the replay header. When a code maps to several room instances, default to the newest one that has player activity (any PLAYER_JOINED) or list the instances and ask for an id. Resolve the optional runId across all instances of the code, not only the newest (needed once run ids become boot-unique).
- **[medium] metrics.decisions.stale is always 0: the regex never matches the reasons Brains actually produces** (`apps/server/src/metrics/index.ts`): Count every REJECTED trace as stale except an invalid-action rejection (reason matching /not offered/), since Brains sets REJECTED only from staleReason(); or match the real phrases (/reset|captured|halted|no shares|no fresh|no longer|stale/i). Alternatively have Brains prefix those reasons with "stale: ". Add a test that feeds real Brains reasons.
- **[medium] Returning to a background tab or reconnecting fires every missed event as one simultaneous effect burst** (`apps/web/src/scene/canvas/CanvasCity.tsx`): In onEvents skip effect creation for stale events while still advancing lastSeq, for example take newest = events[events.length - 1].simTimeMs and continue when newest - e.simTimeMs is more than about 2500 ms. Alternatively re-prime (lastSeq = top, no effects) when the previous frame was more than about 1 s ago.
- **[medium] Ambient traffic is mounted without keepClear, so decorative cars drive through NPC agents, job markers and spawns** (`apps/web/src/scene/canvas/CanvasCity.tsx`): Pass keepClear when the layer is created, for example the x,z of every non-police entry in P.npcs plus MISSION_SPOTS, SPAWN_POINTS.OUTLAW and SPAWN_POINTS.HUNTER from @vice/contracts. It is static geometry read once, which is what the option was added for.
- **[medium] After two quick connection drops, or a failed re-join, the client is 'connected' but no longer in the room** (`apps/web/src/net/socketClient.ts`): Call resync(true) from the connect handler. If a resync is already in flight, remember that another one is needed and run it when the first settles. Handle !ack.ok: on ROOM_NOT_FOUND call leaveRoom() and show the join screen with the message; on other errors retry with backoff. Surface a 'resyncing' or 'detached' state in conn so the header badge and the tape cap show it.
- **[medium] Duplicated tab shares one session: wallet updates reach only the newest socket, and leaving it marks the original player disconnected** (`apps/server/src/transport/socket.ts`): In the join handler, when the returned player is already bound to another live Socket.IO socket, either evict that socket (delete its sessions entry, make it leave the room and emit a 'session moved to another tab' notice that the web client turns into the join screen), or track a set of sockets per player: emit wallet.update to all of them and call engine.disconnect only when the last one closes.
- **[medium] Dev preview page renders hard-coded decisions under a green 'DREX: LIVE' badge** (`apps/web/src/components/wow/DecisionSpotlight.preview.tsx`): Replace the header badge with the 'PREVIEW · MOCK DATA' badge already used in TickerTapePreview.tsx, add a persistent mock watermark to every preview page, use obviously fake request ids, and keep preview pages out of screenshots and the demo.
