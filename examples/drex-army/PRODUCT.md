# Drex Army vs LLM Army

**What:** a live spectator UI for a real-time capture-the-flag match between two AI-commanded armies (Drex vs an LLM), plus benchmark results.

**Who / where:** hackathon judges and audience watching on a projector in a bright venue, 3–5 m away; the presenter drives it from a laptop. Glanceable from a distance beats dense.

**Job:** make one claim legible in seconds: the faster brain issues fresher orders and wins. The head-to-head numbers (decisions/sec, latency, order age, cost) and the map must read instantly.

**Tone:** a situation room / briefing board. Precise, calm, confident. No neon gamer chrome, no SaaS dashboard cards.

**Colors carry meaning:** blue = Drex army, red = LLM army. Nothing else uses those hues.
