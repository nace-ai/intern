# NearMiss AI web dashboard

Aviation themed Next.js and shadcn/ui frontend for the Builder A ASRS data service and Builder B analysis service.

Run the setup in the [project README](../../README.md). The frontend listens on `http://127.0.0.1:3000` by default. It reads the 5,127 real NASA ASRS reports (incidents July 2023 – June 2024) from the local Builder A API. Agent decisions and citations appear only after Builder B's service returns them.
