# ASRS sample manifest

- Source: [NASA ASRS Database Online](https://asrs.arc.nasa.gov/search/database.html), CSV export from the official query wizard.
- Query: `Date of Incident was between July-2023, June-2024`; no event or narrative filter.
- Downloaded: November 14, 2026 (America/Los_Angeles), through the official query wizard's CSV export.
- Local raw file: `data/asrs_jul2023_jun2024.csv` (excluded from Git).
- SHA-256: `2d0027d75847c0bb2a6ce9dcd24aa4dba950ed116d93ab8b7cb9b3b78a5c04eb`.
- Exported rows: 5,127, with 5,127 unique ACNs, 5,127 primary narratives, and 5,127 synopses (the 10,000-row export cap is not reached).
- Reports per month (`Time/Date`): 2023-07 415, 2023-08 414, 2023-09 362, 2023-10 381, 2023-11 370, 2023-12 371, 2024-01 412, 2024-02 377, 2024-03 499, 2024-04 498, 2024-05 522, 2024-06 503. NASA's own date field also places 3 records outside the query window (one each in 2023-02, 2023-03 and 2024-09); they are kept as exported, and the dashboard's displayed period ignores months holding under 1% of the records.
- Earlier file: the first import used `data/asrs_june_2024.csv` (503 reports, SHA-256 `50d6001a1ef7f241ee9552d570d8fd96c76210a367e887e979272991fa6fe6ec`). All 503 of those reports are present in the current export with identical narratives and Primary Problem codes, so saved demo runs and the `asrs_case_*.json` fixtures remain valid. Their related-report lists were computed against the June-only corpus and may differ when regenerated.
- CSV layout: two header rows (group and field), one blank row, then one row per incident; 126 columns. `ACN` is the stable source identifier. `Date` is `YYYYMM`, so day-level precision is unavailable. `Report 1 / Narrative` is the primary original narrative. `Report 2 / Narrative` is optional supplemental text and is retained separately.
- Field mapping in DuckDB: `ACN → acn`, `Time/Date → report_month`, `Report 1/Narrative → narrative`, `Report 2/Narrative → supplemental_narrative`, `Report 1/Synopsis → synopsis`, `Events/Anomaly → anomaly`, `Assessments/Primary Problem → primary_problem`, `Person 1/Communication Breakdown → communication_breakdown`, `Person 1/Human Factors → human_factors`, `Aircraft 1/Flight Phase → flight_phase`, `Place/Locale Reference → locale`, and `Time/Local Time Of Day → local_time`. The `raw_fields` JSON column retains all 126 original values with their group and field names, including other expert-coded fields.
- Missing in this sample (blank cells): local time 696, locale reference 473, Person 1 human factors 906, Person 1 communication breakdown 3,487, Report 2 narrative 3,982, flight phase 143, anomaly 1, primary problem 2. Values are counts of blank cells, not assessments of safety.
- Source caveat: ASRS reports are voluntary and NASA does not verify or validate them. Counts in this sample do not measure accident prevalence or risk.
- Coding caveat: `Primary Problem` has 17 distinct values in this sample, led by Human Factors (1,842), Aircraft (1,548), Procedure (587), and Ambiguous (460). These are source codes, not validated ground-truth labels for the agent taxonomy. Do not equate text matches or coded counts with causal or risk estimates.
- Initial communication focused demo candidates: ACN `2134849` (pushback and ground personnel communication), ACN `2126005` (opposite direction ground conflict and radio issue), and ACN `2133280` (runway selection and ATC communication). These are selected for inspection, not validated labels or model outcomes.

Reproduce the export by opening the source link, selecting **Start Search**, adding **Date of Incident**, setting the begin date to **July 2023** and the end date to **June 2024**, running the search (it should report 5,127 ACNs), and choosing **Comma Separated File (CSV)**. The download is named `ASRS_DBOnline.csv`; rename it to `data/asrs_jul2023_jun2024.csv` locally and confirm the SHA-256 above. Import with `python -m data_pipeline.asrs import data/asrs_jul2023_jun2024.csv --sample "NASA ASRS Database Online; incident dates July 2023 - June 2024; CSV exported 2026-11-14"`. ASRS caps one export at 10,000 records, so larger windows need several exports.
