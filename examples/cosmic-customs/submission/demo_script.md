# Demo script

Open http://127.0.0.1:8000/ and leave the network idle. Say that the scoreboard is a recorded replay, then read the mode label before any number.

1. Point at the queue of ten showcase shipments. Select a second shipment and show that the manifest text and the privileged oracle label change. The oracle label is for the auditor. It is not printed on the packet and it is not sent to the models.

2. Open Certificate and Note. Use Show source and show the highlighted quote in the document that contains it.

3. Stay on Text. Say that the live scoreboard is the completed 100-case held-out decision test (Drex 89/100, OpenRouter 95/100, zero failures on both, measured 2026-11-14). The five-case development pilot is the smaller sample in the deck, and it is not the held-out result.

4. Switch to Documents. For TST-056, read the Drex verdict on extracted evidence and the frontier verdict on that same extraction. Mention the one settled document cost of $0.12 and that the packet was not field-perfect.

5. Press the Inspect button only if asked. With the default configuration it is labeled MOCK and does not call Drex or OpenRouter. If the server was started with `APP_MODE=live`, say so first: each click makes one real Drex and one real OpenRouter decision call and spends a little of the configured budget. Never start `benchmark_ndi.py --limit 10` during the demo; the one NDI packet already paid for and remains the document evidence.

Close by stating the sample-size limit: one 100-case held-out sample of a fictional rulebook, plus five development cases and one NDI packet. No setting changed after the development freeze.
